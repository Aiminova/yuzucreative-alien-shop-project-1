# [Yuzu Creative - Alien Shop Game Project]

This repository contains the core files and structures of a game project on which I performed basic-level QA (Quality Assurance) processes.

## Project Status and Scope

This project is not a commercial or large-scale production that is actively developed and continuously updated. Rather, it serves as a **basic draft, prototype, and infrastructure study**. 

* **Update Status:** No new updates or content additions are currently being made to the project; it is maintained in its current state as a fixed foundational design.
* **Project Type:** It is an entry-level prototype where game mechanics and basic architecture were tested.

## Note on QA (Quality Assurance) Processes

Due to the current structure of the project (being a basic draft and receiving no active updates), this repository does not feature extensive QA documentation, large bug/issue logs, or continuous test scenarios. 

However, during this working process;
* Functionality checks of core mechanics,
* Stability tests,
* Basic bug hunting and reporting habits

and other foundational practices of the QA discipline have been applied here. This repository is included in my personal portfolio to demonstrate how a quality assurance perspective is positioned in a basic game project.
